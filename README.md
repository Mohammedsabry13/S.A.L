# S.A.L for Logistics Services — Corporate Website

A professional corporate website for **S.A.L for Logistics Services**, an Alexandria-based cargo shipping and logistics company founded in 2025, operating Export, Import and Operations divisions.

## 🛠️ Tech Stack
- **HTML5 & CSS3** — semantic structure and custom styling
- **Bootstrap 5.3** — responsive grid, offcanvas mobile menu
- **WOW.js + Animate.css** — scroll-triggered animations
- **Bootstrap Icons & Font Awesome 6.7** — dual icon sets
- **Plus Jakarta Sans** — Google Fonts typography
- **Vanilla JavaScript** — certificate popup modal, form handling

## ✨ Features
- Fullscreen hero section with 4-slide background carousel
- Hero social media icons sidebar (desktop only)
- Hero slide counter with up/down navigation arrows
- Sticky navbar with Bootstrap offcanvas mobile menu
- About Us, Services & Industries sections
- Contact & inquiry form with Subject field and WhatsApp button
- AAST Certificate popup modal with overlay dismiss
- Footer with 3 department email cards (export / import / ops)
- Fully responsive across all screen sizes
